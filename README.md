## ◈ Featured Projects

<details>
<summary><b>◆ Atlas Intelligence — AI Startup Directory & Intelligence Platform</b></summary>

<br/>

> Enterprise-grade startup intelligence platform built as the primary internship deliverable at **TheAISignal**. A full-stack Next.js 15 application with a structured data layer, modular component architecture, and pixel-accurate design implementation.

The platform surfaces AI company profiles with deep intelligence layers — investor graphs, patent data, ecosystem mapping, competitor analysis, alumni networks, and funding timelines — delivered through a production-quality frontend engineered for recruiter and investor audiences.

| Attribute | Detail |
|---|---|
| **Stack** | Next.js 15, React 18, TypeScript, Tailwind CSS 3.4, Cloudflare Pages |
| **Architecture** | App Router, RSC-first, selective `use client`, ISR-ready data layer |
| **Performance** | Hydration-safe floating-point SVG, SSR-compatible component patterns |
| **Design System** | Custom glassmorphism, 3D SVG icons, multi-layer inset box-shadows |
| **Data Layer** | `companyProfile.ts` typed schema — backend-swap-ready |
| **Deployment** | Cloudflare Pages with GitHub org webhook integration |
| **Impact** | Primary product deliverable; evaluated by company leadership |

**Key engineering highlights:**
- Built `EcosystemGraph.tsx` — SVG-based node graph with cubic Bézier connectors, PILL_WIDTHS lookup, clip-path circular center logo, per-category color coding across seven node types
- Engineered `InvestorsAndPatentSection`, `CompetitorAndCollectionSection`, `AlumniAndSimilarSection` with synthetic sine-wave sparklines and modulo-based color cycling
- Implemented math-driven floating card positioning via trigonometric `pt(angle, radius)` and `floatY` Y-axis-only CSS animations
- Resolved hydration mismatches from floating-point SVG coordinate precision using `parseFloat(value.toFixed(4))`
- Built category page data pipeline correcting `categoryUtils.ts` shape mismatch via `getCategoryCounts()` in `startups.ts`

<br/>
</details>
