## 🚀 Projects

<details>
<summary>&nbsp;<b>DevArena &nbsp;—&nbsp; Developer Events & Real-Time Collaboration Platform</b></summary>
<br/>

> A platform for developers to discover hackathons, coding contests, and technical events — with real-time team formation and live notifications.

**Problem solved:** Developers had no centralised place to find and join tech events or form teams. DevArena brings event discovery, team collaboration, and notifications into one application.

| | |
|:---|:---|
| **Stack** | MongoDB · Express.js · React.js · Node.js · Socket.io · Redux Toolkit |
| **Auth** | JWT session management + Google OAuth 2.0 |
| **Real-Time** | WebSocket layer via Socket.io for team chat and live notifications |
| **State** | Redux Toolkit slices across events, teams, and user domains |

- Built a dual authentication system supporting both JWT and Google OAuth 2.0 from scratch
- Implemented real-time team collaboration using Socket.io WebSocket architecture
- Designed the full REST API surface with middleware-based validation and role-based access

<br/>
</details>

<details>
<summary>&nbsp;<b>CareerMate &nbsp;—&nbsp; AI-Powered Resume Analyzer</b></summary>
<br/>

> An AI tool that scores resumes against ATS criteria and generates personalised career intelligence — skill gap reports, role-match scores, and learning roadmaps.

**Problem solved:** Job seekers don't know why their resumes get rejected. CareerMate gives them a concrete ATS score with actionable improvement steps, powered by an LLM.

| | |
|:---|:---|
| **Stack** | React.js · Node.js · Express.js · MongoDB Atlas |
| **AI** | Groq API — LLaMA 3.3 70B with structured JSON prompt engineering |
| **Auth** | JWT with protected middleware on all AI routes |
| **Analysis** | Formatting · keyword density · readability · job-role alignment |

- Integrated Groq's LLaMA 3.3 (70B) with structured prompts to produce deterministic, parseable JSON outputs
- Built ATS scoring pipeline evaluating resumes across multiple dimensions
- Implemented job-role matching with LLM-generated skill gap identification and step-by-step roadmaps

<br/>
</details>

- Built complete CRUD pipeline from database schema through API to UI
